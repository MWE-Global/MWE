# MWE Display Project Resources
Practical templates for planning digital signage, commercial display, and touch display projects.
Visit [MWEdisplay](https://www.mwedisplay.com/) for current product information.
## Start here
| Resource | Use it when |
| --- | --- |
| [Display project brief](display-project-brief.md) | Defining the installation environment, content workflow, and acceptance criteria |
| [CMS integration checklist](cms-integration-checklist.md) | Evaluating a content management system with a specific screen and player configuration |
| [External Windows touch commissioning](touch-commissioning-checklist.md) | Checking the separate picture and touch-input paths before handoff |
| [Local pointer input test](touch-input-test.html) | Downloading a small browser tool to observe pointer input on the connected PC |
Copy the brief into your project notes, complete the fields, and assign an owner to each open item. Use the integration checklist to keep requirements, test results, and unresolved questions together.
