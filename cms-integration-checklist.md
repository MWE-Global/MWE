# CMS Integration Checklist

Use this checklist for a specific display, media player, and CMS configuration. Record evidence rather than assuming that compatibility with one configuration covers every model.

## Before testing

- [ ] Confirm which party provides the screen, player, CMS, and installation.
- [ ] Identify the supported content formats, resolution, and orientation for the selected configuration.
- [ ] Record how content is assigned to a display or display group.
- [ ] Confirm the network requirements with the site administrator.
- [ ] Assign the person responsible for access permissions and account recovery.
- [ ] Agree on restart, offline playback, update, and support expectations.

## Handoff

- [ ] Record the tested configuration and any exclusions.
- [ ] Record open issues, their owners, and the next action.
- [ ] Provide the operator with the agreed content update procedure.
- [ ] Confirm who handles screen, player, CMS, and network support.
- [ ] Retain the test record with the project brief.
